## 진단

- 증상("쫒·찟이 하얗게 보임")의 원인은 글자 누락이 아니라 **윤곽선이 0개인 빈 글리프**.
  cmap에는 11,172자 전부 매핑돼 있었음.
- 한나체 Pro는 어떤 판본이든 같은 구조(실글자 2,518 + 빈 글리프 8,654)여서
  다른 곳에서 이식할 수 없음 → 직접 조립이 유일한 방법.
- 실글자 2,518자 중 144자는 **음식 일러스트**(원본의 의도된 컨셉)였음 → 진짜 글자로 교체.

## 방법 (자소 분해·조립)

1. 신뢰 donor 2,374자를 초성/중성/종성으로 분리.
   - 폰트 내장 **호환 자모 51자(ㄱ~ㅣ)를 절대 기준**으로 분리 후보를 채점 (chamfer 거리)
   - 융합 획(ㄱ+ㅠ, ㅜ+ㄱ 등 한 컨투어로 붙은 경우) 검출 게이트 다수
2. 누락 글자별 우선순위 조립:
   - **A 받침교체** 6,603자 — (초성+중성) 통째 유지, 받침만 교체 (예: 쫒 = 쫄의 ㅉㅗ + 곶의 ㅈ)
   - **C/C2 초성교체** ~450자 — 모음+받침 유지, 초성만 교체 (C2는 모음·받침 융합 글자용)
   - **V 모음교체** — 무받침 글자 (예: 뺴 = 빼의 ㅐ→ㅒ)
   - **B 받침추가** ~870자 — 무받침 글자 세로 압축 + 받침 삽입
   - **D 완전조립** ~1,230자 — 부품 3개를 통계 박스에 배치 (잉크 충돌 검사 포함)
3. 검증 루프: 전수 FreeType 렌더 → 멀티에이전트 시트 검수 5라운드
   (232 → 11 → 24 → 122 → 3건으로 수렴, 최종 라운드 잔여 건은 전수 확대 검수로 false positive 확인)
   - 회귀 스위트: 역대 지적 글자 376자 — 전부 정상 확인

## 품질 한계 (정직한 고지)

- 조립된 8,798자는 실제 한나체 획으로 만들어 스타일은 일관되지만,
  디자이너가 한 자씩 그린 원본 2,374자만큼의 미세 조정은 없음.
- 특히 복합모음+겹받침의 극희귀 조합은 받침이 다소 비좁게 보일 수 있음.
- 원본과 구별되도록 폰트 이름은 "BMHANNAPro Hangul11172"로 별도 등록됨.
