# BM HANNA Pro — 한글 11,172자 완성판 (비공식)

> 문서 목적: 이 폰트가 무엇인지, 설치 방법, 라이선스 조건을 안내합니다.
> 스타일: 한국어, 이모지 없이 간결하게, 비개발자 기준의 단계별 설명, 라이선스는 원문 인용 우선.

배달의민족 한나체(BM HANNA Pro)는 한글 11,172자 중 자주 쓰는 2,518자에만 실제 글자가 있어,
`쫒`, `찟`, `떄`, `뀪` 같은 글자를 입력하면 빈 칸으로 표시됩니다.

이 폰트는 기존 글자들에서 자음·모음 조각을 추출·조립하여
모든 한글 조합 11,172자를 채운 비공식 확장판입니다.
원래 있던 2,374자는 1픽셀도 수정하지 않았습니다.

![미리보기](showcase_final.png)

이 저장소는 우아한형제들·산돌과 무관한 비공식 파생본이며, 문제 시 배포를 중단합니다.

## 설치 방법

[Releases](../../releases)에서 `BMHANNAPro_Hangul11172.ttf` 를 다운로드하세요.

### Windows

1. 이전에 이 한나체를 설치한 적이 있다면 먼저 삭제:
   `설정 > 개인 설정 > 글꼴`에서 "배달" 검색 → 옛 한나체 제거 → PC 재부팅
2. 다운로드한 ttf 파일 우클릭 → "모든 사용자용으로 설치"
   (메뉴에 없으면 더블클릭 → 왼쪽 위 [설치] 버튼)
3. 메모장에서 이 서체 선택 후 `쫒` 입력 → 글자가 보이면 성공
4. 안 보이면 PC를 한 번 재부팅

또는 ttf와 `install-windows.bat`를 같은 폴더에 두고 bat 파일을 더블클릭해도 됩니다.
(보안 경고가 뜨면 "추가 정보 → 실행" — 폰트 복사만 하는 스크립트입니다)

### macOS

1. ttf 파일 더블클릭 → [설치] (이전 버전이 있다면 [대치])
2. 이전에 이 한나체를 쓰던 Mac이라면 폰트 캐시 비우기가 필요합니다.
   `응용 프로그램 > 유틸리티 > 터미널`에서 아래 한 줄 입력 후 엔터 (로그인 비밀번호 입력):
   ```
   sudo atsutil databases -remove
   ```
3. 사용하던 앱(메모 등)을 완전히 종료(Cmd+Q) 후 다시 열기

### 확인

메모장/메모 앱에서 이 서체를 선택하고 `쫒기다, 옷을 찟다` 를 입력해보세요.
모든 글자가 보이면 정상입니다.

### 음식 그림 이스터에그에 관하여

공식 한나체 Pro는 의도적으로 다음 컨셉의 폰트입니다:

> "배달의민족 한나체 Pro는 맛있는 음식 이미지가 구석구석 숨어있는 서체입니다.
> 한글 조합은 되지만 실제로는 잘 쓰이지 않는 글자를 음식 이미지로 대체하여
> 타이핑할 때 뜬금없이 음식 그림이 뿅! 나왔다 사라집니다." — [우아한형제들](https://www.woowahan.com/fonts)

즉 `쫒` 같은 글자가 안 보이는 것은 버그가 아니라 원래 의도였습니다
(희귀 글자 144자는 음식 그림, 나머지 8,654자는 빈 칸).
이 완성판에서는 해당 컨셉을 제거했습니다.

| | 공식 한나체 Pro | 이 완성판 |
|---|---|---|
| 희귀 글자 144자 (옧, 똠 등) | 음식 그림 | 진짜 한글 |
| 나머지 8,654자 (쫒, 찟 등) | 빈 칸 | 진짜 한글 |

검증: 한글 음절 11,172자 전부에서 음식 그림 0개, 한글 입력이 음식 글리프로
치환되는 GSUB 규칙 없음. 타이핑 중 음식 그림이 나오는 일은 없습니다.
이스터에그를 원하면 공식 한나체 Pro를 사용하세요.

## 제작 방법 (요약)

1. 신뢰할 수 있는 기존 글자 2,374자를 초성·중성·종성으로 자동 분리
   (폰트에 내장된 호환 자모 51자를 기준 모양으로 채점)
2. 누락 글자별 최적 전략으로 조립:
   받침교체(`쫒` = `쫄`의 ㅉㅗ + `곶`의 ㅈ받침) → 초성교체 → 모음교체(`뺴` = `빼`의 ㅐ→ㅒ) → 압축+받침추가 → 완전조립
3. 11,172자 전수 렌더링 검증 + AI 멀티에이전트 시각 검수 5라운드

상세 과정은 [REPORT.md](REPORT.md), 조립 파이프라인은 `phase*.py` 스크립트 참고 (재실행 가능):

```bash
python3 -m venv .venv && ./.venv/bin/pip install fonttools Pillow numpy
./.venv/bin/python phase2_parts.py && ./.venv/bin/python phase3_compose.py && ./.venv/bin/python phase4_validate.py
```
